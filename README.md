# Kassia Vieira — Advocacia e Consultoria Jurídica

Base de um site institucional em Next.js, inspirado na identidade visual dos cartões enviados.

## Identidade visual

- Vinho/bordô: `#6B2638`
- Off-white: `#F7F4EF`
- Bege acinzentado: `#D8D0C7`
- Grafite: `#292727`
- Dourado discreto: `#B99A62`

## Stack

- Next.js
- React
- TypeScript
- CSS
- Lucide React

## Rodando localmente

```bash
npm install
npm run dev
```

Depois abra `http://localhost:3000`.

## Próximos passos

1. Substituir o elemento visual da balança pela logo oficial em SVG/PNG.
2. Inserir fotos profissionais da advogada.
3. Confirmar áreas de atuação e textos jurídicos.
4. Confirmar telefone, e-mail, Instagram e cidade/endereço.
5. Revisar o conteúdo conforme as regras de publicidade profissional da OAB.
6. Configurar domínio `.com.br` e publicar na Vercel.
